# Levelling

## What levelling does

Levelling measures **vertical height differences** between points. The result is a set of Reduced Levels (RLs) — heights relative to a chosen datum (mean sea level in Nepal).

Result magnitudes: Backsight (BS), Foresight (FS), Intermediate Sight (IS). Computation rule:

```
Height of Instrument (HI) = RL of BM + BS
RL of next point        = HI − FS (or IS)
```

## The instruments

- **Level** (auto, dumpy, or digital) — gives a horizontal line of sight.
- **Staff** — graduated rod, held truly vertical.
- **Tripod** — head levelled approximately, then legs fixed.

## Temporary adjustments (the routine)

1. Set up the tripod, fix the instrument.
2. Level the instrument using the three foot-screws (bullseye bubble centered).
3. Focus the eyepiece to your eye.
4. Take BS on the Bench Mark (BM).

## Booking

Two common methods:

| Method | Formula | Use |
| --- | --- | --- |
| Height of instrument (HI) | RL = HI − FS | Simple, less bookkeeping |
| Rise & fall | Rise/Fall = previous RL − current staff reading | Better error checking |

> Error check on every page: the sum of BS minus the sum of FS must equal the first RL minus the last RL. If it doesn't, you've booked something wrong.
